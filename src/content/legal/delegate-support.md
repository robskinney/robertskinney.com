Delegate is a native iOS and Android client for [Manager.io](https://www.manager.io), for both self-hosted Manager Server and Manager Cloud.

Delegate is an independent, unofficial app. It isn't made, endorsed, or supported by Manager.io, so please contact us, not Manager.io, about problems with the app. For questions about Manager itself (your accounts, reports, or server), use [Manager.io's own support](https://www.manager.io).

## Contact

- **Something not working?** [Report a problem](https://github.com/robskinney/delegate-support/issues/new?template=bug.yml) on GitHub.
- **Have an idea?** [Request a feature](https://github.com/robskinney/delegate-support/issues/new?template=feature.yml).
- **Prefer email?** Write to rockettutoring@outlook.com. Please include your device model, operating system version, and Delegate version (shown in Settings).

The **Report a Problem** and **Request a Feature** buttons in Delegate's Settings open the same forms with your app version and device already filled in. GitHub issues are public, so never post your server address, access token, or business details there.

## Getting started

1. In Manager, open your business and go to **Settings › Access Tokens**, then create a token.
2. In Delegate, tap **Add Business** and enter the address you use to open Manager in your browser, along with the token. On iPhone and iPad, the address must start with https:// unless the server is on your local network.
3. Add more businesses the same way and switch between them from the business menu at the top of any tab.
